# Examen práctico: Prepara tu noche de cine

Este ZIP incluye la estructura de Vite + React + TypeScript, una maqueta HTML/CSS y los datos. **No incluye la implementación de React ni los tipos**, para que los desarrolles tú.

## Contenido

- `maqueta.html`: referencia visual estática de la interfaz.
- `src/styles.css`: estilos de la maqueta.
- `src/datos.ts`: datos iniciales de productos, películas y géneros, sin tipos explícitos.
- `src/App.tsx`, `src/main.tsx` y `src/components/`: archivos vacíos con indicaciones TODO para que implementes la estructura y el código.

## Para empezar

1. Abre la carpeta en Visual Studio Code.
2. Ejecuta `npm install`.
3. Usa `maqueta.html` como referencia para construir los componentes React.
4. Implementa los archivos TSX y los tipos según el enunciado.
5. Cuando hayas creado el punto de entrada y los componentes, ejecuta `npm run dev`; comprueba al final con `npm run build`.
