1. ¿En qué archivo está el punto de entrada de la aplicación? ¿Qué hace la función `createRoot`?
En el main.jsx de la carpeta src. createRoot crea una raíz en el documento HTML para
los componentes de React y toma un elemento DOM donde colocar
los componentes de React, que en este caso es el elemento con el ID «root».
createRoot devuelve un objeto que contiene una función render

2. ¿Cuál es el ID del elemento HTML donde se monta la aplicación? ¿En qué archivo está definido?
El id es root y está definido en main.jsx
